## 📌 О проекте

**Defender Eye** создан для того, чтобы превратить разрозненные логи и алерты безопасности в элегантный, информативный и наглядный **киберпанельный дашборд**, визуально вдохновленный интерфейсом **3X-UI**:

* 🌘 **Глубокий темный SOC-интерфейс** с неоновыми акцентами, карточками KPI и радарной сеткой.
* ⚡ **Realtime-поток инцидентов** на базе Server-Sent Events (SSE) с мгновенной отрисовкой атак.
* 🌐 **100% автономная векторная карта атак** на HTML5 Canvas с лазерными траекториями (без обращений к внешним сервисам вроде Google Maps, OpenStreetMap или Mapbox).
* 🛡️ **Сквозное шифрование (E2EE):** рукопожатие RSA-OAEP/SHA-256 и поток AES-256-GCM для безопасного приема данных от агентов [Open Defender](https://github.com/fridalif/open-defender).
* 🚀 **Единый статический бинарник:** веб-панель React 19 полностью скомпилирована внутрь Go-бинарника (`//go:embed all:dist`). Для работы **не нужны Docker, Node.js, Nginx, Redis или PostgreSQL**.

## 🎯 Профиль ресурсов: 1 CPU / 2 GB RAM

Панель специально спроектирована для работы на самых доступных VPS-серверах:
- **Потребление RAM:** ~35–60 МБ при активном потоке атак.
- **Потребление CPU:** < 0.5% (чтение `/proc` и быстрые срезы SQLite).
- **Диск:** база данных SQLite с режимом WAL и автоматической ротацией старых записей.

## ⚡ Ключевые возможности

### 1. 📊 Оперативный центр (SOC Dashboard)
4 ключевые метрики (Атаки 24ч, Уникальные IP, Активные баны, Аппаратная нагрузка сервера), встроенный мини-радар атак, рейтинг стран-агрессоров и интерактивный список активных блокировок с таймерами до разбана.

### 2. ⚡ Журнал событий безопасности (Events Log)
Фильтрация по уровню угрозы (`critical`, `high`, `medium`, `low`), типу действия (`blocked`, `alerted`, `logged`) и векторам атак (`ssh_brute`, `web_recon`, `web_brute`, `db_brute`, `port_scan`, `resource_overload`). Клик по строке открывает модальное окно с расшифрованным JSON-пейлоадом и деталями сетевого пакета.

### 3. 🌐 Автономная карта угроз (Threat Map)
Векторная визуализация на Canvas с анимированными лазерными дугами, связывающими геолокацию атакующего с защищаемым сервером. Работает полностью локально через встроенную геометрию континентов и локальную базу MaxMind MMDB.

### 4. 🛡️ Реестр блокировок (Bans & Blocks)
Мониторинг адресов, отправленных в бан подсистемой iptables/nftables. Отображение времени блокировки, причины и живого обратного отсчета ("осталось 14м 30с").

### 5. 🔍 Досье атакующих IP (IP Registry)
История рецидивов по каждому адресу, принадлежность к автономным системам (ASN) и провайдерам хостинга (DigitalOcean, Hetzner, AWS, OVH, Tor Exit Nodes).

### 6. 🔑 Специализированный SSH Brute-force монитор
Отдельный экран для анализа атак на порт 22: частота попыток подбора, используемые логины и распределение источников.

### 7. 🚪 Анализ разведки портов (Port Recon)
Рейтинг сканируемых портов (22, 80, 443, 3389, 3306, 5432, 6379, 8080) с индикацией степени риска и рекомендациями по закрытию периметра.

### 8. 💻 Системная телеметрия хоста
Прямое считывание метрик ядра Linux из `/proc/stat`, `/proc/meminfo`, `/proc/loadavg` и `/proc/net/dev`: графики использования CPU, RAM, Swap, диска, средняя нагрузка (1m/5m/15m) и скорость сетевого интерфейса (RX/TX).

### 9. ⚙️ Интеграция & Симулятор (Demo Mode)
Генератор готовых конфигураций `config.yaml` для Open Defender, ротация данных (7, 14, 30, 60, 90 дней), управление симулятором атак и автономной базой MaxMind.

## 🚀 Быстрый старт

### Способ 1: Установка через готовый DEB-пакет (Ubuntu / Debian) — Рекомендуется

В разделе [**Releases**](https://github.com/Bragoo312/defender-eye/releases) доступны официальные `.deb` пакеты для архитектур `amd64` (x86_64) и `arm64`:

```bash
# 1. Скачайте пакет под вашу архитектуру (например, amd64):
curl -sLO https://github.com/Bragoo312/defender-eye/releases/download/v1.0.0/defender-eye_1.0.0_amd64.deb

# 2. Установите одной командой:
sudo apt install ./defender-eye_1.0.0_amd64.deb
# или через dpkg:
# sudo dpkg -i defender-eye_1.0.0_amd64.deb
```
*Пакет автоматически создаст изолированного системного пользователя `defender-eye`, выставит безопасные права, создаст конфигурацию в `/etc/defender-eye/config.yaml`, настроит изолированную службу `systemd` и сразу же запустит её.*

---

### Способ 2: Установка через терминал (Git / Скрипт)

Выполните установку через терминал:

```bash
git clone https://github.com/Bragoo312/defender-eye.git /opt/defender-eye
cd /opt/defender-eye
sudo bash scripts/install.sh
```

Инсталлятор автоматически:
1. Определит архитектуру сервера (`x86_64` или `arm64`).
2. Создаст изолированного пользователя `defender-eye`.
3. Скопирует статический бинарник в `/usr/local/bin/defender-eye`.
4. Загрузит актуальную офлайн-базу GeoIP (города и страны) для карты угроз.
5. Настроит права доступа и конфигурацию в `/etc/defender-eye/config.yaml`.
6. Зарегистрирует и запустит защищенную службу `systemd`.

> [!TIP]
> Обновить или загрузить базу данных GeoIP можно прямо из веб-панели (вкладка **«Настройки»** ➔ кнопка **«Обновить базу GeoIP сейчас»**) на лету без перезапуска сервиса, либо из терминала: `sudo bash scripts/download-geoip.sh`.

## 🔒 Безопасный доступ через SSH-туннель

Defender Eye слушает локальный интерфейс `127.0.0.1:8080`, не создавая уязвимостей в открытом интернете.
Для подключения с вашего компьютера откройте терминал и выполните:

```bash
ssh -L 8080:127.0.0.1:8080 user@ip-вашего-сервера
```

После этого откройте браузер:
👉 **[http://localhost:8080](http://localhost:8080)**
