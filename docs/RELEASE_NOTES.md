## 🚀 Defender Eye v1.3.0 — Большое обновление функционала и надежности

### 🛡️ Что нового в версии 1.3.0:

* **🔍 Аудит открытых сетевых портов сервера:**
  Новая вкладка **«Порты»** теперь в реальном времени считывает слушающие сокеты ядра Linux (`/proc/net/tcp` и `/proc/net/tcp6`), определяет связанные службы (`sshd`, `nginx`, `redis`, `mysql`, `postgres` и др.), уровень риска и дает понятные рекомендации по защите сервисов, доступных наружу (`0.0.0.0`).
* **🛠️ Встроенный eBPF Авто-патчер для Open Defender:**
  Автоматическое определение установленного агента Open Defender (v1.3.1+), проверка и исправление известной проблемы переворота байт IP/портов (Endianness) в один клик с безопасным бэкапом и перезапуском службы.
* **🌐 Обновленный Cyber Radar на Карте угроз:**
  Неоновые границы государств, режим «Все векторы из базы» (до 5000 атак), выбор страны с подгрузкой всей истории и аппаратно-ускоренная отрисовка Canvas (Path2D батчинг) без просадок FPS даже на бюджетных ноутбуках.
* **⚡ Быстрое управление IP из досье:**
  В модальном окне IP-адреса появилась панель моментальных действий: блокировка на 1 час, 24 часа, навсегда, снятие бана или добавление в белый список с отправкой команды на агент.
* **⏱️ Настраиваемая частота телеметрии:**
  В Настройках доступен выбор интервала опроса системных метрик CPU, RAM, диска и сети (1s, 2s, 3s, 5s, 10s).
* **🧰 Стабилизация ядра и защита от сбоев:**
  Устранена гонка WebSocket-записи, ликвидирована утечка горутин пинга, исправлен подсчет свободного диска через `syscall.Statfs`, добавлена защита от переполнения памяти (MaxBytesReader) и плавный debounce-поиск в журнале событий.

### 📦 Быстрая установка и обновление

```bash

sudo apt install --reinstall ./defender-eye_1.3.0_amd64.deb
```

## 🛡️ Defender Eye v1.1.0 — Включение eBPF Anti-Reconnaissance и Центр Безопасности

### 📋 Что нового:
* **eBPF сетевой мониторинг из коробки:** модуль перехвата сетевой разведки портов переведен в штатный режим мониторинга (`logger`).
* **Центр управления безопасностью:** 6-модульный интерфейс в Настройках для конфигурирования правил защиты SSH, Web, БД, сканирования портов и списков исключений с синхронизацией по защищенному WebSocket E2EE.
* **Автоматическое восстановление соединений:** агенты Open Defender корректно восстанавливают зашифрованный канал при перезапуске сервера мониторинга.

**Установка:**
```bash
curl -sLO https://github.com/Bragoo312/defender-eye/releases/download/v1.1.0/defender-eye_1.1.0_amd64.deb
sudo apt install ./defender-eye_1.1.0_amd64.deb
```

## ⚙️ Defender Eye v1.0.2 — Поддержка Journald и универсальный Syslog

### 📋 Что нового:
* **Автоопределение ОС:** поддержка как классического `syslog` / `/var/log/auth.log` (Debian/Ubuntu), так и `journalctl` (современные дистрибутивы без rsyslog) без ручной настройки.
* **Улучшенная стабильность службы:** корректная работа под systemd-песочницей на дистрибутивах Ubuntu 22.04 / 24.04 и Debian 11 / 12.

## 🔧 Defender Eye v1.0.1 — Исправление синхронизации E2EE ключей

### 📋 Что нового:
* **Стабильность рукопожатия:** устранена перезапись конфигурации при повторном первичном подключении агента.
* **Универсальные регулярные выражения SSH:** повышенная точность обнаружения перебора паролей и невалидных пользователей OpenSSH.
